# Algorithm Performance & Equivalence Comparator

A lightweight Python platform to evaluate, verify, and benchmark two distinct algorithms performing the same task.

## Features
- **Equivalence Verification**: Checks whether both algorithms generate identical outputs.
- **Time Complexity Benchmarking**: Measures exact execution time using high-resolution timers (`time.perf_counter`).
- **Space/Memory Profiling**: Tracks peak heap memory usage using Python's `tracemalloc`.

## How to Run
```bash
python app.py
